# Developer Utilities & Workflow Automation (`tools`)

A centralized, lightweight repository for custom scripts, terminal shortcuts, and system configurations. This repository serves as a personal "Swiss Army knife" to automate repetitive tasks, optimize system environments, and streamline daily development workflows across different shells and operating systems.

## 📂 Repository Architecture

```text
D:\dev\tools\
├── git/      # Git configuration files, global aliases, and client-side hooks
├── other/    # Miscellaneous configurations, binary assets, and experimental tools
├── python/   # Multi-platform Python utility scripts and automation modules
├── shell/    # POSIX-compliant shell scripts, functions, and cross-shell aliases (Bash/Zsh)
└── win/      # Windows-specific automation, PowerShell scripts (.ps1), and batch files (.bat)
